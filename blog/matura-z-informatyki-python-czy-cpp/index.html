Matura z informatyki: Python czy C++? Co wybrać i dlaczego

Autor: Grzegorz OlszewskiOpublikowano: 16 listopada 2026Aktualizacja: 16 listopada 2026

W skrócie: dla większości maturzystów lepszym wyborem jest Python — programy na pliki z danymi pisze się w nim szybciej i krócej, a duże liczby nie przepełniają typów. C++ warto wybrać, jeśli już go dobrze znasz, startujesz w olimpiadzie informatycznej albo idziesz na studia, gdzie C++ jest pierwszym językiem. Na samej maturze oba języki pozwalają zdobyć komplet punktów.

Jak wygląda matura z informatyki w formule 2023

  • tylko poziom rozszerzony, 210 minut, 50 punktów,
  • cały egzamin przy komputerze — zadania teoretyczne i praktyczne w jednym arkuszu,
  • zadania praktyczne: programowanie (najczęściej przetwarzanie pliku tekstowego z danymi), arkusz kalkulacyjny i bazy danych (SQL),
  • język programowania wybierasz z listy ogłaszanej przez CKE — są na niej m.in. C++, Java i Python,
  • termin główny w 2027 roku: 17 maja 2027, godz. 9:00.

Zadania programistyczne na maturze rzadko wymagają ekstremalnej wydajności. Liczy się to, czy w ograniczonym czasie napiszesz poprawny program, który wczyta dane, policzy wynik i zapisze odpowiedź.

To samo zadanie w obu językach

Typowe zadanie maturalne: plik liczby.txt zawiera po jednej liczbie całkowitej w wierszu. Policz, ile z nich to liczby pierwsze.

Python

def pierwsza(n):
    if n < 2:
        return False
    d = 2
    while d * d <= n:
        if n % d == 0:
            return False
        d += 1
    return True

with open("liczby.txt") as f:
    liczby = [int(w) for w in f]

print(sum(1 for n in liczby if pierwsza(n)))

C++

#include <fstream>
#include <iostream>
using namespace std;

bool pierwsza(long long n) {
    if (n < 2) return false;
    for (long long d = 2; d * d <= n; d++)
        if (n % d == 0) return false;
    return true;
}

int main() {
    ifstream plik("liczby.txt");
    long long n;
    int ile = 0;
    while (plik >> n)
        if (pierwsza(n)) ile++;
    cout << ile << endl;
}

Algorytm jest identyczny. Różnica to ilość kodu i rzeczy, o których trzeba pamiętać: w C++ dobór typu (long long), w Pythonie zamiana tekstu z pliku na liczbę (int(w)). Przy zadaniach na napisach (np. sprawdzanie palindromów, zliczanie liter) przewaga Pythona jest jeszcze większa.

Kiedy wybrać który język

Wybierz Pythona, jeśli:

  • zaczynasz naukę programowania w liceum lub masz na nią mniej niż 1,5 roku,
  • Twoim celem jest dobry wynik z matury, a nie olimpiada,
  • chcesz szybko pisać programy przetwarzające tekst i dane.

Wybierz C++, jeśli:

  • uczysz się go od lat i swobodnie w nim piszesz,
  • startujesz w olimpiadzie informatycznej,
  • Twoja szkoła uczy C++ i nie chcesz uczyć się drugiego języka równolegle.

Najgorsza opcja to przeskakiwanie między językami w klasie maturalnej. Wybierz jeden i opanuj go porządnie.

Co jest ważne niezależnie od języka

  • Algorytmy z podstawy programowej — sortowanie, wyszukiwanie binarne, NWD (algorytm Euklidesa), sito Eratostenesa, systemy liczbowe, rekurencja.
  • Arkusz kalkulacyjny i SQL — za te zadania jest sporo punktów, a wielu uczniów ćwiczy je za mało.
  • Praca na plikach CKE — rozwiązuj zadania z arkuszy z poprzednich lat na oryginalnych danych.
  • Zarządzanie czasem — 210 minut mija szybko; ćwicz pełne arkusze na czas.
